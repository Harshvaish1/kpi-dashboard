## Results you can talk about
Part 1
- 11,195 active customers, 42,551 completed orders, about $40.4M revenue, average order value about $950
- 75% of customers placed more than one order
- Furniture (about 44%) and Electronics (about 29%) make up roughly 3/4 of revenue in every region

Part 2 (churn = no completed order in the 90 days before 2026-09-30; customers who signed up 90+ days earlier only; 10,844 customers)
- Overall churn: 68.4%
- Top 3 drivers by lift: discount-dependent customers (avg 10%+ discount) churn at 79.1% vs 64.8% for others; customers whose first order was under 100 churn at 76.9% (vs 67.4% for 300+); Consumer segment churns at 73.7% vs 59.2% for Corporate
- Drivers stack: discount-dependent customers who also had a returned order churn at 83.4% vs 62.5% for the lowest-risk group
- Revenue at risk: about $23.2M lifetime revenue sits with churned customers, $11.3M of it Consumer
- Caveat to say out loud in interviews: effect sizes are modest and the data is simulated; the point is the method (defining churn, building a feature view, ranking drivers by lift, checking combinations)

## Power BI build (Power BI Desktop on Windows; the mobile app can only view reports)
1. Get Data > Text/CSV: load all four CSVs. Set `order_date` and `signup_date` to Date type.
2. Model view: customers 1-* orders, orders 1-* order_items, products 1-* order_items (on the ID columns).
3. Date table: `Calendar = CALENDAR(DATE(2024,1,1), DATE(2026,12,31))`, relate to orders[order_date], mark as date table.
4. Calculated column on order_items: `Revenue = order_items[quantity] * RELATED(products[unit_price]) * (1 - order_items[discount])`
5. Measures:
```
Total Revenue = CALCULATE(SUM(order_items[Revenue]), orders[status] = "Completed")
Total Orders = CALCULATE(DISTINCTCOUNT(orders[order_id]), orders[status] = "Completed")
Active Customers = CALCULATE(DISTINCTCOUNT(orders[customer_id]), orders[status] = "Completed")
Avg Order Value = DIVIDE([Total Revenue], [Total Orders])
Revenue LY = CALCULATE([Total Revenue], SAMEPERIODLASTYEAR('Calendar'[Date]))
YoY Growth % = DIVIDE([Total Revenue] - [Revenue LY], [Revenue LY])
Return Rate % = DIVIDE(CALCULATE(DISTINCTCOUNT(orders[order_id]), orders[status]="Returned"), DISTINCTCOUNT(orders[order_id]))
```
6. Layout: 5 KPI cards (Revenue, Orders, Active Customers, AOV, Return Rate); monthly revenue line chart; revenue by category bar; revenue by region; slicers for Year, Region, Segment; top-customers table. Optional drill-through page per region.
