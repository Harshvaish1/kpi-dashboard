# Operational KPI Dashboard (Power BI)

An interactive Power BI dashboard for sales and customer KPIs, built on a 4-table star-schema model
with DAX measures, slicers, and a drill-through page.

> **Data note:** the data in `data/` is **synthetic** (generated by the companion `customer-analysis` project).

## Data sources (4 CSV files in `data/`)
`customers.csv` (12,000) | `products.csv` (40) | `orders.csv` (48,261) | `order_items.csv` (120,333)

## Build steps (Power BI Desktop, Windows)
1. **Get Data > Text/CSV**, load all four files. In Power Query set `order_date` and `signup_date` to **Date** type, then Close & Apply.
2. **Model view**, create relationships (all one-to-many, single direction):
   `customers[customer_id] 1-* orders[customer_id]`, `orders[order_id] 1-* order_items[order_id]`, `products[product_id] 1-* order_items[product_id]`.
3. **Calendar table** (Modeling > New table): `Calendar = CALENDAR(DATE(2024,1,1), DATE(2026,12,31))`. Add columns `Year = YEAR('Calendar'[Date])`, `Month = FORMAT('Calendar'[Date],"MMM")`, `MonthNo = MONTH('Calendar'[Date])`. Relate `Calendar[Date] 1-* orders[order_date]`, then Mark as date table. Sort `Month` by `MonthNo`.
4. **Calculated column** on `order_items`:
   `Revenue = order_items[quantity] * RELATED(products[unit_price]) * (1 - order_items[discount])`
5. **Measures** (create a "Measures" table):
```
Total Revenue    = CALCULATE(SUM(order_items[Revenue]), orders[status] = "Completed")
Total Orders     = CALCULATE(DISTINCTCOUNT(orders[order_id]), orders[status] = "Completed")
Active Customers = CALCULATE(DISTINCTCOUNT(orders[customer_id]), orders[status] = "Completed")
Avg Order Value  = DIVIDE([Total Revenue], [Total Orders])
Revenue LY       = CALCULATE([Total Revenue], SAMEPERIODLASTYEAR('Calendar'[Date]))
YoY Growth %     = DIVIDE([Total Revenue] - [Revenue LY], [Revenue LY])
Return Rate %    = DIVIDE(CALCULATE(DISTINCTCOUNT(orders[order_id]), orders[status] = "Returned"), DISTINCTCOUNT(orders[order_id]))
Revenue 3M Avg   = AVERAGEX(DATESINPERIOD('Calendar'[Date], MAX('Calendar'[Date]), -3, MONTH), [Total Revenue])
Revenue % of All = DIVIDE([Total Revenue], CALCULATE([Total Revenue], ALL(customers), ALL(products)))
```
6. **Page 1 - Executive Overview:** KPI cards (Total Revenue, Total Orders, Active Customers, Avg Order Value, Return Rate %, YoY Growth %); line chart of Total Revenue and Revenue 3M Avg by Month; clustered bar of revenue by `products[category]`; bar/map of revenue by `customers[region]`; slicers for Year, Region, Segment.
7. **Page 2 - Customer Detail (drill-through):** table with `customer_name`, `segment`, Total Orders, Total Revenue sorted by revenue; add `customers[region]` to the page's **Drill-through** well. Right-click a region on Page 1 and choose Drill through > Customer Detail.
8. Save the report as `kpi-dashboard.pbix`.
